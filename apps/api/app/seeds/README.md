`scripts/seed.py` orqali yuklanadi:

- `protocol_templates.json` — 4 ta protokol shabloni (T-02 / T-13)
- `exercises_uz.json` — kamida 120 nutq elementi (T-09)
- `needs_uz.json` — 40 ta asosiy ehtiyoj, tarjimon lug'ati (T-11)
- demo akkauntlar — `scripts/seed.py` (T-02), 14 kunlik tarix — `scripts/demo_data.py` (T-17)
